COMMON QUESTIONS

Before you get started.

How much does a smart contract or custom build cost?

Pricing depends on functionality, supported networks, integrations, testing requirements and delivery scope. Start with a project inquiry so CBL can provide a tailored quote.

Can I request multiple services together?

Yes. Describe the combined scope — for example, a token contract, website and community moderation — in the inquiry form.

Does using the contract scanner mean a token is safe?

No. Automated checks can flag common concerns but cannot guarantee contract safety, liquidity or project legitimacy. They are not a substitute for professional security review.

Can I use the swap and scanner without hiring CBL?

Yes. The swap, scanner and projects area are separate platform features accessible from the Crypto Tools section.
