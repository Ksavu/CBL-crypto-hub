# CBL Bartender photos

Put these two files in this folder (img/bartender/). The pages show them automatically; until then a violet gradient is shown.
The real CBL logo is placed on top by the page, so the photos must NOT contain any text or logos.

| File | Size | Used on |
|---|---|---|
| `hero.jpg` | 1600×1000 (16:10), under 400 KB | Homepage Bartender section, Bartender sign-in page |
| `pour.jpg` | 1600×1000 (16:10), under 400 KB | Bartender install page |
